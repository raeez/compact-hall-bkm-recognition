# Compact Hall Geometry and Finite-Height Positive Borcherds Recognition

Raeez Lorgat

Extensions of coherent sheaves provide the geometric input for a compact Hall algebra. We ask when specified classes in such an algebra realize the positive part of a Borcherds algebra. We then prove finite-height recognition for a fixed, purely even Borcherds presentation in symmetric monoidal height truncations. Relations construct the canonical enveloping-to-generated-Hall surjection. Homogeneous dimensions can prove that it is an isomorphism. An independently constructed Hall-to-enveloping quotient gives another criterion and determines the additional kernel in the full Hall algebra. Compatible comparisons extend to the specified height completion. Reduced critical coefficients, coherent orientations, and the compact bialgebra comparison remain necessary for the geometric realization.
