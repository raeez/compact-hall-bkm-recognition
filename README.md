# Finite-Height Positive Borcherds Recognition and the Compact Hall Problem

The paper proves that scalar denominators do not recover Lie or enveloping
products, defines symmetric-monoidal height truncations, and gives separate
finite-height criteria for a positive Borcherds Lie algebra and for its
associatively generated enveloping image. It distinguishes the canonical
enveloping-to-spherical-Hall map from the additional compatible
Hall-to-enveloping quotients needed in finite windows. It also states the exact
formal height completion and isolates the strong-orientation, Hall-map, PBW,
coproduct, kernel, and topology hypotheses still missing from a compact
Calabi--Yau realization.

Build with `make check`.
