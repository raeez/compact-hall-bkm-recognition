# Agent Rules

## Golden rule: no project management at any scale whatsoever in the manuscript

Every reader-facing line contains mathematics, never agents, prompts, audits,
repair history, workflows, tasks, commits, tests, progress, ownership, or
revision chronology. The rule applies to all structural levels and PDF
metadata. State exact theorem, hypothesis, conditional, conjectural, and open
status. Archive claims are untrusted leads. Verify source algebras, brackets,
orientations, PBW statements, limits, and comparisons independently.

Use Witten's 1980s problem-first expository architecture as a structural model,
without imitating wording. Pass these rules to every subagent.
